# IMS Made Simple — Support Site

Public support and privacy policy page for [IMS Made Simple](https://apps.apple.com/) by JMW Developers LLC.

## Live URL

Once GitHub Pages is enabled: `https://jmwinc2026-coder.github.io/ims-support/`

## Setup Instructions

1. Create a new public repository on GitHub named `ims-support` under the `jmwinc2026-coder` account.
2. Upload `index.html` to the repository root.
3. Go to **Settings → Pages**.
4. Under **Source**, select:
   - Branch: `main`
   - Folder: `/ (root)`
5. Click **Save**. GitHub will give you a URL like `https://jmwinc2026-coder.github.io/ims-support/`.
6. Wait 1–2 minutes for the first deploy.

## Sections

- `#contact` — Support email and response time
- `#faq` — Frequently asked questions
- `#privacy` — Privacy policy (anchor: `#privacy`)
